How to run a fast, defensible takeoff with this tool

  1. Lock your defaults first. Cover, grade, waste % and lap/anchorage methodology set here become the starting point for every element — you only need to override where a drawing says otherwise. This is exactly how a QS sets up a Cordell or CostX workbook before touching a single element.
  2. Tick only what exists on this job in the Elements tab. A clean library keeps the Workspace uncluttered — you can always come back and tick more later.
  3. Add one instance per distinct size/type. Two different pier diameters on the same job? Add two Bored Pier instances. The engine keeps each fully independent, so nothing gets averaged or blended.
  4. Chase the load path with Connections. Pier → pile cap → column → beam/slab. Enter starter bars once at the source element and link forward — the target shows it as "incoming" for visibility, but it is only counted once commercially. This mirrors how a structural engineer reads a bar schedule: reinforcement belongs to the pour it's cast into, but continuity is drawn through.
  5. Use the Results tab on every card to sanity-check. A concrete volume, a bar length, a ligature count — each one shows its formula. If a number looks wrong, the formula tells you exactly which input to fix, same as auditing a spreadsheet cell.
  6. Export early, export often. CSV opens straight into Excel for pricing; the PDF is your clean takeoff report for a file note or client submission.

Import / Attach Takeoff Files

A CSV markup/quantity export — from Bluebeam Revu's "Markup Summary" export, any other takeoff/QS tool, or a CSV saved out of a workbook — drafts one workspace element per row, matched to an element type by keyword (checked against a Subject/Label-style column if there is one, every cell in the row if not) and prefilled from whichever measurement column it finds (count, length, area or volume, falling back to the first plain number in the row). Every imported element is tagged ⚠ From CSV import — verify, so open it, check the geometry/measurement mapped correctly, and correct anything wrong before pricing. An Excel or PDF file is attached to this project for reference (auto-drafting elements straight from a workbook isn't supported yet — save/export it as CSV first) — you can remove any attached file below once you no longer need it.

Project Setup

Defaults & Rules

These are project-wide defaults. Every element can override cover, grade, laps and anchorage individually.

🎓
Cover is set per element type, not one flat number: a bored pier cast against soil, a suspended slab formed both sides, and an external driveway exposed to weather all carry different exposure classifications under AS 3600 — so each element type in this tool loads its own sensible starting cover (piles ~65mm, suspended slabs ~25mm, driveways ~45mm, etc.), shown on every card next to the cover field. The "Fallback cover" here only applies to element types with no specific default. Always override on the card if your durability/exposure classification differs.
👷
Waste % vs Lap %: concrete waste covers spillage, over-break and pump priming (3–7% typical). Reinforcement waste covers offcuts from stock-length bars (2–4% typical). Lap % is a separate allowance again — it only applies where a continuous bar run is longer than your bar stock length and must be spliced/lapped to continue; the engine applies it automatically to long runs (slab and wall distribution bars, mesh, footing bars) and shows it as its own column in every export, never folded into waste.

Element Library

Tick every element / category that exists on this project. Only ticked elements appear in the Workspace, where you can add as many instances (and as many different types/sizes) of each as needed.

💻
Under the hood every ticked type is a self-contained calculator — geometry in, quantities out. Foundations, columns, walls and slabs are purpose-built (matching AS 3600 practice); everything else (earthworks, driveways, repairs) uses a flexible generic calculator so nothing on the library is ever a dead end.

Workspace

💻
Each card rolls up to a one-line summary — name, ID and live concrete/reinforcement/formwork totals — once you're done with it. Click the ▾/▸ arrow to collapse or re-open any single card, or use the buttons above to roll up the whole workspace once your inputs are in.

Quantity Register

Every calculated quantity, fully auditable — element, formula, quantity, waste and linked elements. This is the single source of truth behind every export. Rolled up by element, same as the Workspace — collapse a group to review it at a glance, or remove the element entirely from here.

Publish to Quote & Cost Planner

Sends every element's quantities straight into the Quotes tool AND the Cost Planner dashboard as a new project in each — concrete, reinforcement and wall formwork prefill against the matching Gradcon catalog product where the match is unambiguous. Anything that isn't (an ambiguous concrete mix, a bar size or formwork system the bridge can't confidently pick, an element type there's no equivalent for) is listed in a flag banner on the new project instead of being guessed. No need to re-enter these quantities by hand in either app.

Spreadsheet Export

Exports as CSV worksheets (open directly in Excel / Google Sheets). Column set matches: Stage | Category | Element | Element ID | Material Group | Material | Specification | Quantity | Unit | Waste % | Final Quantity | Formula | Linked Element | Notes.

👷
CSV is the pricing file — one worksheet per material group, ready to paste rates against in Excel. PDF is the clean report — project header, defaults, element-by-element breakdown and grand totals, suitable for a file note, client submission or subcontractor RFQ pack. Both pull from the same live Quantity Register, so they can never disagree with each other.

Order Schedule

Every quantity measured across the whole takeoff, summed into one ordering line per material — concrete by grade, bars by size, mesh by type, formwork, excavation, the lot. Untick anything you don't want on this order (already ordered, by others, priced elsewhere) — the totals and the CSV follow the ticks, and your ticks save with the takeoff.
